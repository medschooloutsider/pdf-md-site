# PDF-MD Reviewability Demo Pack

This pack is a safe synthetic proof asset for PDF-MD. It is designed to show the review step, not to claim perfect OCR or perfect academic summarization.

## What is inside

- `source/research-methods-field-notes.pdf` - synthetic academic/research source document.
- `source/source-transcript.md` - plain-text reference for what the source document was intended to contain.
- `output/research-methods-field-notes_Hybrid_norm.md` - Markdown generated through the PDF-MD benchmark/export harness.
- `audit/research-methods-field-notes_Hybrid_norm.audit.json` - audit sidecar generated by PDF-MD for the same run.
- `audit/review-notes.md` - human review notes explaining what to inspect and what not to overclaim.
- `run/benchmark-profile.json` and `run/summary.json` - the bounded proof profile and run summary.

## How to read it

Open the source PDF and the Markdown output side by side. The useful question is not whether every line is perfect. The useful question is whether PDF-MD gives you a workable Markdown draft while keeping the source, output, and audit trail inspectable.

## Caveats

PDF-MD output still needs review. OCR and layout reconstruction can vary by document, scan quality, fonts, columns, equations, tables, and image regions. This sample is synthetic and safe to publish; it is not a guarantee for every academic PDF.

PDF-MD is available for Mac as a one-time purchase. Inspect this sample first, then decide whether the workflow fits your documents.
